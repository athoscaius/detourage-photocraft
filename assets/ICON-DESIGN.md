# Icône de Détourage PhotoCraft

Dessin fourni par l’utilisateur. Source originale : `provided-icon.png`, conservée telle quelle. Le script prépare les tailles ICNS macOS en gardant le dessin et sa transparence, dans un canevas de 1024 pixels avec une zone de dessin de 824 pixels. Aucun fond coloré ou nouveau dessin n’est ajouté.
